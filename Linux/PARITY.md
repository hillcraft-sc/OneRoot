# Linux parity tracker

Single source of truth for what the Linux app has. Update a row when a phase ships it. `L/` = `Linux/Sources/OneRootLinux/`. Phases (L0-L10) are in the Linux 1.0 plan; the dev guide is `docs/LINUX-DEV.md`.

Status words: **Done**, **Partial**, **Service only** (logic in the shared core, no GTK UI), **None**.

Goal: full parity with the Mac app except Mac-only features (iCloud, Spotlight, Touch ID, Full Disk Access, NetFS/Keychain specifics).
